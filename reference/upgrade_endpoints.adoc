= Astra API (ACS) upgrade endpoints
:imagesdir: ../media/

[.lead]
Find the software components that are eligible for upgrade and start the upgrades. The packages you register determine which upgrades are available.

The Upgrade App API provides access to software components that are eligible for upgrade, and to initiate upgrades. The availability of upgrades is determined based on packages registered with the Packages API.
