= Astra API (ACS) feature endpoints
:imagesdir: ../media/

[.lead]
Check which Astra Control features are enabled or disabled by reading the feature flags.

The Feature API provides read-only access to feature flag resources in order to determine which features are enabled or disabled in the system.
